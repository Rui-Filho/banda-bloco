# 🎸 BLOCO — Site Oficial

Site oficial da **BLOCO**, banda brasileira de rock alternativo autoral.

O projeto foi desenvolvido com foco em identidade visual, apresentação do trabalho da banda, navegação intuitiva e adaptação para diferentes tamanhos de tela.

## 🌐 Acesse o site

[Visite o site oficial da BLOCO](https://rui-filho.github.io/banda-bloco/)

---

## 📖 Sobre o projeto

O site da BLOCO foi desenvolvido para apresentar a banda, sua identidade, discografia, lançamentos e demais conteúdos relacionados ao projeto musical.

Além da construção da interface, o desenvolvimento envolveu diversas etapas de ajustes visuais e técnicos, incluindo responsividade, navegação em dispositivos móveis, organização dos elementos e refinamento da experiência do usuário.

O projeto também serviu como oportunidade para aplicar, em um projeto real, conhecimentos adquiridos durante os estudos de desenvolvimento web.

---

## ✨ Principais características

- Design personalizado para a identidade visual da banda
- Layout responsivo
- Menu de navegação adaptado para dispositivos móveis
- Seção de apresentação da banda
- Discografia e lançamentos
- Links para plataformas digitais e redes sociais
- Elementos visuais e efeitos desenvolvidos com CSS
- Estrutura otimizada para diferentes tamanhos de tela

---

## 📱 Responsividade

O site foi desenvolvido para funcionar em diferentes dispositivos, incluindo:

- 💻 Desktops
- 💻 Notebooks
- 📱 Smartphones
- 📱 Tablets

Durante o desenvolvimento foram realizados testes e ajustes específicos para dispositivos móveis, principalmente na navegação e na organização dos elementos da interface.

---

## 🎨 Identidade visual

A identidade visual do site foi desenvolvida considerando a proposta artística da BLOCO e sua estética relacionada ao rock alternativo.

Foram utilizados recursos de composição, tipografia, cores, imagens e elementos gráficos para criar uma experiência visual coerente com o projeto musical.
